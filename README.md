# 需求分析
该程序旨在深入挖掘社交平台上用户的看法、评论和讨论，以了解公众对话题的认知和态度。
分析的重点可能包括用户对话题的使用体验、对其技术能力的评价，以及相关的社会舆论。通过对大量文本数据进行情感分析、关键词提取，该程序希望揭示用户的普遍看法，识别潜在的问题或争议，并为相关领域的研究和发展提供有价值的见解。
通过及时捕捉和分析这些信息，该程序可以为相关机构、研究人员和开发者提供及时的反馈和参考，以更好地理解公众对这些技术的态度，并推动相关领域的发展和改进。

## 程序需要完成的功能：
（1）数据清洗

首先，需要从爬虫数据中分离出可使用的数据，故需要使用具有分离筛选无关数据的代码进行清洗。清洗代码用于去重、去除特殊字符、英文、标点符号等。

（2）分词处理

在数据清洗后，为了让数据可使用，还要做进一步的分词处理。

（3）数据可视化

完成情绪量化后，可以做进一步的数据可视化，引入词云、情感打分变化趋势图等关键图像模块，反映出情感变化趋势和各平台的均值差异。

（4）情感分析

完成数据分析后，可以切入核心：对情感的变化趋势进行分析。情感分析涉及分析正向评价分词和负向评价分词，并按照情感的强烈程度进行打分，作情感的初步量化。

# 程序设计
（1）程序主要模块

数据处理模块（ReadData）:从原始数据中读取评论数据，并进行初步清洗。

转换日期格式、删除空缺值等。

文本清洗模块（TextClean）:

对评论文本进行清洗，去除HTML标签、特殊字符、英文、标点符号等。

分词模块（cut_word_mark）:

利用jieba分词对评论文本进行分词。

去除停用词，但保留特定词性的词，如名词、动名词、专有名词、时间、成语等。

情感分析模块（calculate_sentiment_score）:

计算每条评论的情感得分。

匹配正面和负面情感词，考虑程度级别词和否定词的影响。

数据分组模块（Group, Group_dx）:

将评论数据按照用户所属平台或评论对象进行分组。

将分组后的数据保存为新的CSV文件。

词云图绘制模块（Draw）:

统计每个评论对象的文本分词结果中的词频。

利用词云图展示词频高的单词。

数据可视化模块（All_data, Platform_sentiment）:

利用matplotlib库绘制评论情感得分的变化趋势图。

分别绘制不同平台对于文心一言和ChatGPT的每日平均正负向评论情感分变化。

（3）需要定义的函数及其算法

ReadData函数：
从原始数据文件读取数据，转换为DataFrame格式，指定列名。
将DataFrame写入指定输出路径。

TextClean函数：
对文本进行正则化，去除HTML标签、特殊字符、英文、标点符号等。

cut_word_mark函数：
利用jieba分词对文本进行分词。
去除停用词，但保留特定词性的词。

calculate_sentiment_score函数：
对文本进行分句，并扫描文本，将文本中出现的正向、负向、程度词与情感词典进行匹配并计分和乘权重，计算单个评论文本的情感得分。

Group函数：
将评论数据按照用户所属平台进行分组，保存为新的CSV文件。

Group_dx函数：
将评论数据按照评论对象进行分组，保存为新的CSV文件。

Draw函数：
使用wordcloud函数绘制词云图，展示评论对象的文本分词结果中词频高的单词。

All_data函数：
利用matplotlib绘制所有平台对于“文心一言”和“ChatGPT”的平均每日评论情感得分变化趋势图。

Platform_sentiment函数：
利用matplotlib绘制每个平台的用户对于不同评论对象的每日平均正负向评论情感分变化。
